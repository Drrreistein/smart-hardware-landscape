# 智能硬件产业研究

以供应链图谱为入口，把这条产业链拆成 **23 个环节、155 家企业**，并附一份行业观察笔记与已覆盖公司的调研报告。

**在线访问**：https://drrreistein.github.io/smart-hardware-landscape/

## 首页有什么

首页顶部附一份 [《智能硬件行业观察笔记》](reports/智能硬件行业观察笔记.html)——个人整理的行业笔记，不是正式研报，数据来自公开信息，仅供参考。

首页是一张可交互的产业链图谱，提供四个视角：

| 视角 | 回答的问题 |
| :--- | :--- |
| 供应链图谱 | 主控 SoC、光学显示、传感器、电池、结构件、代工、品牌、渠道，各自有哪些玩家？ |
| 按品类 | 清洁电器、可穿戴与音频、智能影像、AI 眼镜、智能家居、AI 玩具，谁在做？ |
| 按应用场景 | 家庭清洁、影音娱乐、运动户外、健康监测、办公学习、老人儿童、宠物、车载，各自谁在供给？ |
| 按玩家模式 | 品牌商、代工与方案、芯片器件、渠道平台、支撑服务，靠什么赚钱？ |

点击带绿点的公司名，直达调研报告；灰色表示暂无报告。

---

## 口径说明

- **供应链图谱含全链条**，上游器件、材料、代工都在。
- **「按品类」「按应用场景」两个视图只收录品牌商、渠道与支撑服务**。上游芯片、光学、传感器、电池、结构件与代工不参与——同一颗蓝牙 SoC 会同时装进耳机、手表和眼镜，按品类归类会失真。
- **「按玩家模式」矩阵含全链条**，包括芯片与代工。因为"卖部件"和"卖整机"是两种完全不同的生意，放在一起才看得出谁在赚谁的钱。
- 企业按"主营业环节"归类，横跨多个环节的公司（如歌尔、小米、华为、立讯）会在多处出现，用"多环节"标记。归类为编辑判断，非官方口径。

## 目录结构

```
.
├── index.html              # 首页：产业链图谱（自包含，无外部依赖）
├── reports/
│   ├── *.html              # 主报告 + 4 份公司研报
│   └── md/                 # Markdown 原稿
├── tools/
│   ├── build_sites.py      # 首页生成脚本（多站点共用，见主工作区）
│   ├── build_reports.py    # 公司研报 Markdown → HTML
│   └── md2simple.py        # 主报告 Markdown → 极简 HTML
└── .gitignore
```

## 维护

- 主报告以 Markdown 为源，用 `md2simple.py` 渲染成极简单栏 HTML；公司研报用 `build_reports.py`（会跳过 `*行业观察笔记.md`，避免覆盖主报告）。
- 首页数据数组位于 `index.html` 底部 `<script>` 中，格式为：

```js
["公司名", ["环节代码"], ["品类代码"], ["场景代码"], "报告文件名或 null", "玩家模式"]
```

- 更新报告后，用主工作区的 `tools/publish.py` 一键渲染并发布：

```bash
python3 tools/publish.py 智能硬件行业观察笔记.md
```
